# ARDENT Creative Arts Website

A responsive static website concept for ARDENT — Artist Resources, Development, Education, Networking & Talent.

## Preview locally
Open `index.html` in a browser.

## Deploy
Import this repository into Vercel. No build command is required; the output directory is the project root.

## Before public launch
- Replace the illustrative imagery with licensed ARDENT photography.
- Add official contact email and business details.
- Connect the inquiry form to a real form endpoint/CRM (currently it opens the visitor's email app).
- Connect Stripe and booking/enrollment systems only after business accounts, products, prices, policies and tax settings are configured.
- Confirm facility plans, tenant terms, accessibility details and program information before publishing as factual offerings.

This is a front-end starter site, not a complete production platform. Payments, accounts, bookings, radio streaming and student records are not yet connected.
